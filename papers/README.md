# Put question papers here

Make one folder per subject, named with the VTU subject code (capital letters):

```
papers/
  BMATS101/
    syllabus.pdf          <- optional but recommended (must be named syllabus.pdf)
    2023-dec.pdf
    2024-jun.pdf
    2024-dec.pdf
    model-paper-1.pdf
```

- Use at least 4-5 past papers for good results.
- Scanned PDFs work too; Gemini reads them.
- Any file name works, except the syllabus must be called `syllabus.pdf`.
